# Claim-to-evidence audit

This register covers the main scientific assertions in the supplied Abstract, Introduction, Methods, Results and Discussion. Numerical details are in [Phase 2](phases/02_RESULTS.md); every original reference has an entry in [the source audit](../references/SOURCE_AUDIT.md).

| Manuscript assertion | Verdict | Evidence / action |
|---|---|---|
| 91 patients and 24 controls | Reproduced | SAV group counts; unique-person status still needs source confirmation |
| Study dates and ethics approval | Author-reported, not independently authenticated | Confirm December 2024–February 2025 and approval 236 dated 7 November 2024 |
| All participants male | Narrative only | No sex column in supplied SAV; author confirmation needed |
| All forensic admissions followed specified offenses | Narrative only | No offense-level variables; do not infer a wholly violent sample |
| Outpatients had no offending history | Unverified | Describe as outpatients unless ascertainment is documented |
| Similar diagnoses / diagnosis percentages | Unresolved/inconsistent | Unlabeled diagnosis codes do not reproduce percentages |
| Controls were matched for age, sex and education | Insufficiently documented | Nonsignificant age test is not evidence of matching; education distributions differ |
| Controls were staff and relatives / staff only | Internally inconsistent | Resolve actual recruitment |
| All continuous variables normal | Contradicted | OUTPUT2 p15, visually checked |
| Character assessed with MPPS-MD | Construct/name error | Use affective temperament and TEMPS-A; confirm form |
| 99 items and cutoffs | Source description, not scoring verification | Need administered questionnaire and validation correction; current analyses are continuous scores |
| All p-values <.000 | Invalid notation | Report p<.001 where appropriate; employment actually .003 |
| Forensic depressive scores higher | Contradicted | 10.09 versus outpatient 12.68 |
| Forensic irritable scores higher | Supported as group mean association | Difference +3.456; GH p=.003; exploratory Holm p=.015 |
| Other patient-group dimensions differ | Not supported at .05 | Cyclothymic, hyperthymic and anxious pairwise comparisons nonsignificant |
| Four patient-control dimensions differ | Supported within dimensions | Both patient groups higher on nonhyperthymic scores; not prevalence |
| Hyperthymic groups equivalent | Not established | ANOVA p=.081; no equivalence design/margin |
| Demographic omnibus tests prove each pairwise contrast | Overstatement | Omnibus chi-square does not specify which pairs differ |
| Recent evidence eliminates psychiatric crime association | Citation mismatch | Ayar abstract does not support it; use bounded current synthesis |
| Male sex universally carries tenfold criminality risk | Unsupported as written | Selected homicide cohorts lack the required population comparator |
| Personality, legal cynicism and affective temperament interchangeable | Incorrect | Different constructs and measurement methods |
| Irritable temperament triggers injury/homicide | Causal overreach | No temporality, aggression outcome or comprehensive confounder adjustment |
| Antipsychotics/court admission explain higher forensic depression | Contradicted and unmeasured | Direction reversed; no medication or depression-symptom data |
| Few bipolar patients explain hyperthymic null | Speculation | Diagnosis mapping unresolved; null does not establish mechanism |
| Temperament influences illness course in this study | Unmeasured | No longitudinal illness-course outcome |
| Findings justify criminality prediction | Unsupported | No predictive model, validation sample or follow-up |

The defensible conclusion is a difference in mean irritable temperament scores between these recruited groups, with uncertainty and design limitations. It does not identify a cause of offending or a clinical screening threshold.
